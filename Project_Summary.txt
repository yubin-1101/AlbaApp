# 졸업 작품 발표 자료: 아르바이트 관리 플랫폼 '알바체크'

## 1. 프로젝트 개요
'알바체크'는 고용주와 아르바이트생(근로자) 모두를 위한 스마트한 근태 및 급여 관리 모바일 애플리케이션입니다. 
복잡하고 번거로운 출퇴근 기록과 급여 정산 과정을 자동화하여 관리의 효율성을 높이고, 투명한 근무 기록을 통해 신뢰 관계를 구축하는 것을 목표로 합니다.

## 2. 주요 기능
### (1) 공통 기능
- **보안 인증**: 고용주와 근로자 유형에 따른 분리된 회원가입 및 로그인 기능 제공.

### (2) 고용주 기능
- **사업장 관리**: 자신의 사업장을 등록하고, 근로자 초대 및 등록을 위한 고유 '지점 코드'를 발급.
- **QR코드 출퇴근**: 출퇴근 인증을 위한 QR코드를 생성하고, 앱 내에서 실시간으로 갱신.
- **근로자 관리**: 지점 코드를 통해 등록을 요청한 근로자를 승인하거나 거절.
- **근태 현황 확인**: 직원별 근무 기록을 캘린더 형태로 한눈에 파악하고, 날짜를 클릭하여 상세 근무 내역(출근/퇴근 시간, 총 근무시간) 확인.
- **급여 관리**: (구현된 기능을 바탕으로) 직원들의 근무 기록을 기반으로 정확한 급여 정산을 지원.

### (3) 근로자 기능
- **QR코드 스캔**: 고용주의 QR코드를 스캔하여 간편하게 출퇴근 시간을 기록.
- **근무 기록 조회**: 자신의 근무 내역을 캘린더를 통해 월별로 확인.

### (4) 커뮤니티 기능
- **게시판**: 모든 사용자가 소통할 수 있는 게시판 기능 제공.

## 3. 사용한 주요 기술 및 도입 이유

### (1) Expo
- **기술 소개**: React Native 앱을 더 쉽고 빠르게 개발, 빌드, 배포할 수 있도록 돕는 프레임워크 및 플랫폼.
- **도입 이유**:
    - **개발 속도 향상**: 네이티브 모듈(Android/iOS) 설정의 복잡함 없이, 순수 JavaScript/TypeScript 코드에 집중하여 초기 개발 시간을 단축했습니다.
    - **편리한 API 제공**: 카메라, 바코드 스캐너 등 디바이스의 네이티브 기능들을 별도의 설정 없이 `expo-camera`, `expo-barcode-scanner` 같은 패키지를 통해 쉽게 활용할 수 있었습니다.
    - **간소화된 빌드 및 배포**: EAS(Expo Application Services)를 통해 복잡한 앱 스토어 및 구글 플레이 스토어 배포 과정을 자동화하고 간소화할 수 있습니다.

### (2) React Native
- **기술 소개**: 하나의 코드 베이스로 iOS와 Android 앱을 동시에 개발할 수 있는 JavaScript 기반 프레임워크.
- **도입 이유**:
    - **크로스 플랫폼**: 한 번의 개발로 두 개의 플랫폼(iOS, Android)에서 동작하는 앱을 만들 수 있어 생산성이 높습니다.
    - **컴포넌트 기반 구조**: React의 재사용 가능한 컴포넌트 구조를 그대로 활용하여 UI를 모듈화하고, 코드의 유지보수성을 높였습니다.

### (3) TypeScript
- **기술 소개**: JavaScript에 정적 타입을 추가한 슈퍼셋 언어.
- **도입 이유**:
    - **코드 안정성 및 버그 감소**: 컴파일 단계에서 타입 오류를 미리 발견할 수 있어, 런타임 에러를 줄이고 애플리케이션의 안정성을 크게 향상시켰습니다.
    - **개발 생산성 향상**: 코드 자동 완성, 타입 추론 등의 기능을 통해 코드의 의도를 명확히 하고, 대규모 프로젝트에서도 유지보수를 용이하게 합니다.

### (4) Supabase
- **기술 소개**: PostgreSQL 데이터베이스를 기반으로 인증, 실시간 API 등을 제공하는 오픈소스 BaaS(Backend-as-a-Service).
- **도입 이유**:
    - **서버리스 아키텍처**: 별도의 백엔드 서버를 구축하고 관리할 필요 없이, Supabase가 제공하는 DB, 인증, API 기능을 통해 프론트엔드 개발에만 집중할 수 있었습니다.
    - **강력한 데이터베이스**: 관계형 데이터베이스인 PostgreSQL을 기반으로 하여 안정적이며, SQL 쿼리와 RLS(Row Level Security)를 통해 세밀한 데이터 접근 제어가 가능했습니다. (실제로 `work_records` 테이블에 RLS 정책을 적용함)
    - **실시간 기능**: 데이터베이스의 변경 사항을 실시간으로 감지하는 기능을 제공하여, 실시간 근태 현황 모니터링과 같은 기능을 손쉽게 구현할 수 있는 확장성을 가집니다.

### (5) React Navigation
- **기술 소개**: React Native 앱의 화면 전환 및 라우팅을 관리하는 라이브러리.
- **도입 이유**:
    - **React Native 표준**: React Native 커뮤니티에서 가장 널리 사용되는 표준적인 내비게이션 라이브러리입니다.
    - **다양한 네비게이션 패턴**: 스택(Stack), 탭(Tab) 등 모바일 앱에 필수적인 다양한 화면 전환 패턴을 손쉽게 구현할 수 있었습니다.

## 4. 데이터베이스 주요 스키마
- **branches**: 고용주가 생성하는 사업장(지점) 정보. 고유한 `branch_code`를 가짐.
- **employees**: 근로자 정보. 특정 `branch_code`를 통해 사업장에 소속됨.
- **attendance**: `employee_id`와 `branch_id`를 기반으로 출퇴근 시간(`clock_in_time`, `clock_out_time`)을 기록.
- **work_records**: 급여 정산을 위한 최종 근무 기록. 근무 시간과 시급(`hourly_wage`)을 저장.
- **(기타)**: `users`, `posts`, `comments` 등 인증 및 커뮤니티 관련 테이블.
